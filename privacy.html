Privacy Policy

Last updated: October 28, 2026

Moktashf Publisher ("the app") is a private tool used only by its owner, Mahmoud Kamal, to upload and schedule videos on his own YouTube channels and social media accounts.

Data the app uses

The app uses the YouTube API Services to upload videos and set their title, description, tags and publish time on the owner's own channels. It uses an OAuth token that the owner granted to his own account. The app does not collect, store or process data from any other user.

Storage

Access tokens are stored as encrypted secrets in the owner's private GitHub repository and are used only to publish the owner's content. No data is sold or shared with third parties.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions.
